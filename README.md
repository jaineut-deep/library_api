# REST API для управления библиотекой. API позволяет управлять книгами, авторами и пользователями. Позволяет отслеживать выдачу книг пользователям.
# В реализации API используется Django Rest Framework (DRF).
#### Данная бэкенд-часть SPA веб-приложения возвращает клиентам JSON-структуры. Данные о сущностях из рабочей среды приложения хранятся на удалённом сервере.
#### Цель проекта: разработать контейнеризированный backend-сервер DjangoREST Framework для SPA-приложения по управлению библиотекой, с возможность отслеживания выдачи книг.
